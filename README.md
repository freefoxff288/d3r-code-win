# D3R Code для Windows

Лёгкий редактор кода для C++ и Python в стиле D3R. Это порт D3R Code с Linux, переписанный под Windows: здесь нет
встроенного терминала, Python-моста и KDE. Всё это делает C++-часть на Qt 6.

## Установка

1. Скачай `D3RCode-windows-x64.zip` из [Releases](../../releases), распакуй и запусти `D3RCode.exe`.
2. Для C++ нужны компилятор и clangd. Обе вещи ставятся одной командой (PowerShell или cmd):
   ```
   winget install -e --id BrechtSanders.WinLibs.POSIX.UCRT.LLVM
   ```
   Там g++, gdb, clangd, clang-format и mingw32-make. Подойдут и MSYS2 (`C:\msys64\ucrt64\bin`), и LLVM из `C:\Program Files\LLVM`:
   редактор сам смотрит в эти папки и в свежий PATH из реестра.
3. По желанию:
   - Python: `winget install -e --id Python.Python.3.13`. Для автодополнения ещё нужен `py -m pip install jedi black`.
   - CMake: `winget install -e --id Kitware.CMake`.
4. Поставил что-то, пока редактор открыт? Нажми **настройки → инструменты → «обновить»**, перезапускать не нужно.

## Что умеет

- **Подсветка** в цветах Visual Studio: ключевые слова, управление, функции, переменные, типы, строки, escape-последовательности, числа, макросы и препроцессор.
- **Автодополнение** и подсказки параметров. C++ работает через clangd, Python через jedi. Ещё есть:
  - переход к определению (F12 / Ctrl+клик);
  - переименование по всему проекту (F2);
  - структура файла (Ctrl+Shift+E).
- **Ошибки на лету.** C++ проверяет `g++ -fsyntax-only`, Python проверяет встроенный компилятор. Ошибки подчёркиваются, F8 переходит к следующей.
- **Запуск (F5)** во встроенной консоли:
  - одиночный `.cpp` собирается через `g++` в `build\`;
  - проект CMake собирается через `cmake` (Ninja или MinGW Makefiles);
  - `.py` запускается через `py -3`.
  - В конце печатаются код выхода, время и пиковая память.
  - Можно сохранить ввод и аргументы (Ctrl+Shift+R). Без сохранённого ввода программа читает его из строки консоли.
- **Консоль.** Когда ничего не запущено, строка ввода выполняет команды `cmd` (`dir`, `git status`, `pip install …`). Ctrl+клик по `main.cpp:12:5` в выводе открывает файл на этой строке.
- **Проекты:**
  - дерево файлов, новый проект C++/CMake или Python (Ctrl+Shift+N);
  - быстрый переход (Ctrl+P), поиск по проекту (Ctrl+Shift+F);
  - удаление в Корзину.
- **Редактор:**
  - несколько курсоров (Ctrl+D, Alt+клик), сворачивание блоков (F9), шаблоны (слово+Tab);
  - форматирование (Shift+Alt+F): clang-format или black;
  - темы и шрифты: Fira Code встроен, Cascadia и Consolas берутся из системы.
- **Файлы Windows:** CRLF и BOM сохраняются как были. Если файл не в UTF-8, он читается как cp1251.

Все клавиши показывает F1.

## Сборка из исходников

Нужны Qt 6.8+ (MSVC 2022 или MinGW) и CMake:

```
cmake -S . -B build
cmake --build build --config Release
build\Release\D3RCode.exe --selftest
```

`--selftest` проверяет C++-часть: подсветку, файлы, процессы, g++, clangd и Python. `--smoke` открывает окно и закрывается через 8 секунд.
Код собирается и на Linux, так удобнее разрабатывать. GitHub Actions собирает zip на каждый push, а на тег `v*` выкладывает релиз.

## Как устроено

| файл | что делает |
|---|---|
| `src/sys.cpp` | Файлы (CRLF/BOM), поиск по проекту, процессы без окна консоли (`CREATE_NO_WINDOW`), время и память программы, `taskkill /T` для остановки, PATH из реестра |
| `src/lsp.cpp` | Клиент LSP к clangd (для MinGW: `--query-driver` и `--target`), clang-format, помощник Python |
| `src/highlighter.cpp` | Подсветка: свой лексер C++ и Python поверх `QSyntaxHighlighter` |
| `qml/pyhelper.py` | jedi, black и проверка синтаксиса. Работает как постоянный процесс, общается строками JSON |
| `qml/Code.qml`, `Editor.qml` | Весь интерфейс |
